# Roof Tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the `/gzroof` command (module `roof`): generate a roof (gable, hip, pyramid or flat) on the walls of the current WorldEdit selection or the build the player looks at, with `-p` preview, `//undo` support, limits, permissions, help-hub entry and en/nl translations — the first missing Arceon tool.

**Architecture:** A pure, unit-tested engine (`modules/roof/engine/RoofPlanner`) turns a region plus per-column wall-top heights into a placement map of shape parts (stairs/slab/full + facing). The command layer (`modules/roof/command/RoofCommand`) obtains the region from the WE selection or from a build scan (`BuildEditor.scan` at the looked-at block), maps parts to concrete `BlockState`s via the parsed FAWE pattern + `VariantResolver`/`StateMapper`, enforces `Limits.Kind.BLOCKS`, shows `-p` previews through `PreviewService`, and applies through `PlayerEdits.async` so `//undo` works. Wiring follows `GeneratorsModule`/`WeatheringModule` exactly: `GzmnModule` in `modules/roof`, registered in `GZMNBuildtools.allModules()`, `config.yml`, `paper-plugin.yml`, `/gz` help entry.

**Tech Stack:** Java 25, Paper 26.2 API, FastAsyncWorldEdit 2.16.1, Maven (`mvn -B verify` = CI), JUnit 5 + Mockito for tests, ArchUnit (`ModuleBoundariesTest`) for module rules.

**Spec:** `docs/arceon-parity-spec.md`, section "1. Roof tool (Phase 1)" — this plan implements that section. Where this plan and the spec disagree, the spec wins.

- New module `modules/roof` implements `core/module/GzmnModule`; it declares **no** module dependencies and uses only `core` + `shared` (ArchUnit `ModuleBoundariesTest` enforces this automatically since it iterates `GZMNBuildtools.allModules()`).

- Block-count limit: `Limits.get(player, Limits.Kind.BLOCKS, config "generation.max-blocks" default 500000)` — reuse the existing key, add no new config key. The count must include fill blocks, not only the surface.
- Preview: a `-p` or `preview` token anywhere in the args (pattern of `GenerateCommand`); the plan is computed with a fixed seed so an applied preview matches what was shown; preview via `previews.show(player, PlayerEdits.ghost(changes), label, applyRunnable)`; apply via `PlayerEdits.async(player, editSession -> { ...setBlock...; return true; }, onError)` — returning true makes `session.remember` run, so `//undo` reverts.
- All player-facing strings go through `Messages`/`tr(...)`; afterwards regenerate `src/main/resources/lang/en.yml` with `mvn test -Dcatalogue.write=true` and add Dutch lines to `src/main/resources/lang/nl.yml` (`MessageCatalogueTest` fails otherwise).
- Tests: engine tests are pure JUnit (no Bukkit), command tests use Mockito mocks like `src/test/.../modules/gradient/MockBukkitIntegrationTest.java`. `mvn -B verify` must be green.
- Match existing style: final classes, records for data, class-level Javadoc like neighboring files, `tr(...)` for help text, no inline comments.

## Review Focus

1. **L-shaped / non-rectangular builds:** the rim must come from actual build columns; a hole inside the bounding box must not get roof blocks. Pinned by a `RoofPlannerTest` case with a missing column.
2. **Overhang columns outside the build** must take the eave height of the nearest column inside, never y=-1. Pinned by test.
3. **Block limit counts fill blocks** (stack-down), not just stairs. Pinned by `blockCount` assertion in test.
4. **Preview determinism:** same seed → identical plan; noise is opt-in (default 0). Pinned by two-run equality test.
5. **Degenerate regions** (span < 3, or no column with a top) → `Plan.problem` set, zero placements, user gets an error message. Pinned by test + command test.

## Interfaces (pinned)

`RoofOptions` (engine):
```java
public record RoofOptions(String style, String axis, int height, int overhang, double noise,
                          boolean stackDown, boolean levelEnds, long seed) {}
```

`RoofPlanner` (engine, pure — depends only on `shared.build.Bounds` and `shared.build.ShapeKind`):
```java
public final class RoofPlanner {
    public record Cell(int x, int y, int z) {}
    /** kind = FULL / STAIRS / SLAB; facing = "north"|"south"|"east"|"west"|null; topHalf = slab type top */
    public record Part(ShapeKind kind, String facing, boolean topHalf) {}
    public record Plan(Map<Cell, Part> placements, int blockCount, String problem) {}
    @FunctionalInterface
    public interface ColumnTops { /** Top wall y at (x,z), or -1 when the column has no build block. */ int top(int x, int z); }
    public static Plan plan(Bounds bounds, ColumnTops tops, RoofOptions options) {}
}
```

`RoofSpec` (engine, implements `shared.params.ParamSpec`):
- `id()` = `"roof"`; `patternNames()` = `["pattern"]`;
- `params()`: `style` = choice("style", "roof shape", "gable","hip","pyramid","flat"); `height` = (0, 0..32, "ridge height, 0 = automatic"); `overhang` = (1, 0..8); `axis` = choice("axis","ridge direction","auto","x","z"); `noise` = (0, 0..4); `stack-down` = (0, 0..1, "1 = fill below the roof down to the walls"); `level-ends` = (0, 0..1, "1 = flat level at the gable ends").
- `usage()` = `/gzroof <pattern> [style=gable] [height=0] [overhang=1] [axis=auto] [noise=0] [stack-down=0] [level-ends=0]`.

Planner algorithm (the body the implementer writes; the tests pin the values):
- axis auto: `x` when `bounds.sizeX() >= bounds.sizeZ()` else `z`. Ridge runs along the axis; the perpendicular span is `span`, center `c = (min+max)/2.0` on the perpendicular coordinate, `halfSpan = span/2.0`. Height `h = height > 0 ? height : max(1, round(halfSpan))`.
- Per column (x,z) in bounds expanded by `overhang` on all four sides: `base = tops.top(x,z)`; when -1 (outside the build) use `tops.top` of the clamped-inside coordinate. `eave = base + 1`. Perpendicular distance `d = |coord - c|`; along-axis end distance `dEnd` (0 for gable). `rise = round(h * (1 - d/halfSpan))`, additionally reduced for hip/pyramid by `max(d/halfSpan, dEnd/(spanAlong/2.0))`; pyramid = hip with zero ridge length. `flat` → rise 0 everywhere. `noise` adds a seeded jitter in `[-noise, noise]` per column (use a `java.util.Random(seed)` hashed by column so it is deterministic). `level-ends` forces rise = h on the outermost ring along the ridge axis.
- Placements per column: a STAIRS part at `(x, eave + rise, z)`, facing away from the ridge on the dominant axis (perp for gable, dominant of perp/along for hip; ridge column (rise == h and gable) gets a top SLAB at the same cell instead of a stair; `flat` places a top SLAB at `eave` in every column). When `stackDown`, also FULL parts from `base+1` up to `eave+rise-1` in that column.
- `problem` = `"Select a bigger area (at least 3 blocks wide) to put a roof on."` when span < 3 or no column has a top; otherwise null. `blockCount` = placements.size().

`RoofCommand` (command):
- `public static final String PERMISSION = "gzmnbuildtools.roof";`
- `public void roof(Player player, String rawArgs, Mode mode, long seed)` where `Mode` is `SELECTION_OR_BUILD` / `BUILD` (for `paint`/`preview` subcommands); `-p`/`preview` token stripped from rawArgs first.
- Input region: for `BUILD`, or when there is no cuboid selection — `PlayerEdits.lookedAt(player, 200)` + `BuildEditor.scan(editSession, click, TargetMode.BUILD, List.of())`, region = `scan.bounds()`, tops = highest `scan.contains(x,y,z)` per column. For a cuboid selection — region from pos1/pos2, tops = topmost non-air block per column via `ExtentBlockSource`.
- Parse args with `BrushArguments.parse(RoofSpec.INSTANCE, rest)`; build `RoofOptions` from `args.choice("style")` etc.
- Map parts to states: parse the pattern once (`WorldEdit.getInstance().getPatternFactory().parseFromInput(...)` as in `GenerateCommand.parsePattern`), evaluate per cell for the base id (`ExtentBlockSource.idOf(state)`, strip suffix via `ShapeKind.fromSuffix`), then FULL → pattern state; STAIRS → `BlockKnowledge.variants().resolve(base, ShapeKind.STAIRS)` + set `facing`/`half=bottom`/`shape=straight`; SLAB → resolve SLAB + `type=top`. Fall back to the FULL state when resolve is empty. Skip cells outside world min/max Y.
- Count check against `Limits.Kind.BLOCKS` before preview/apply (error message like `GenerateCommand`: `"That roof has %d blocks, above your limit of %d."`).
- Preview: collect `Map<BlockVector3, BlockState>` and `previews.show(player, PlayerEdits.ghost(changes), "a " + style + " roof", () -> apply(player, changes))`; apply re-runs `PlayerEdits.async` writing the same map, success message `"Roofed the build: %d blocks. //undo reverts it."` / for selection `"Placed a %s roof (%d blocks). //undo reverts it."`.

`RoofModule` (module): like `GeneratorsModule` — id `"roof"`, description, `HelpEntry.of(HelpEntry.Category.BUILDS, Material.BRICK_STAIRS, "/gzroof", tr("Roof"), tr("Put a gable, hip, pyramid or flat roof on the walls of your selection or the build you look at.")).example("/gzroof stone_brick_stairs").permission(RoofCommand.PERMISSION)`, register literal `gzroof` with alias `"roof"`: no-arg → usage list; `paint`/`preview` literals → BUILD mode; greedy `args` → parse + run.
