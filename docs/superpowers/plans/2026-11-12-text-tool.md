# Text Tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `/gztext` + `/gzfont` inside the existing `pixel-art` module: render text with a bundled bitmap font as blocks on the wall you look at — spec §6, Phase 2 feature 4.

**Architecture:** Pure engine `modules/pixelart/engine/TextFont` (5x7 glyphs for A-Z, 0-9, punctuation; `render(text, size)` → boolean grid). `modules/pixelart/command/TextCommand` parses `<block> <size> <text> [-p]`, enforces the `image` limit (`pixel-art.max-size`), places via the same wall-plane math as `PixelArtCommand`, previews via `PreviewService`, applies via `PlayerEdits.async` (`//undo`). Registered in `PixelArtModule` as `gztext`/`text` and `gzfont`/`font`, reusing permission `gzmnbuildtools.pixelart`.

**Tech Stack / Spec:** Java 25, Paper 26.2, FAWE 2.16.1, `mvn -B verify` = CI, JUnit 5 + Mockito. Spec: `docs/arceon-parity-spec.md` §6.
